# 「天格」全栈复刻 — 详细设计

> 接口统一前缀 `/api/v1`；响应壳 `{code, msg, res}`，`code=0` 成功；错误 `{code, msg, reason}`（失败 `http_status` 与 `code` 一致，401/402/500 等）。

## 2. 费用与配额明细（`services/beans.py`）

| 业务 | 每日免费 | 单次豆 |
|---|---|---|
| fortune.today / thisWeek / thisMonth / thisYear / thisDayun / oneLife | 1 | 5 / 10 / 15 / 30 / 20 / 50 |
| qian.64gua / guanyin / zhuge | 1 | 5 |
| paipan.liuyao / meihua / xiaoliuren / qimen / daliuren | 1 | 15 / 15 / 5 / 15 / 15 |
| name.nameAnalysis / nameOpt / phone | 1 | 40 / 40 / 20 |
| mingshu.bazi / ziwei / tianming / ten_year | 0 | 40 / 40 / 60 / 40 |
| hepan | 0 | 99 |

算法：`charge()` 先查当日该业务免费次数（`BeansLog.reason='free'`），未用完 → 记一次 free（扣 0 豆）；
已用完 → `实际扣豆 = cost × VIP折扣`，余额不足抛 `402 InsufficientBeans`。每次调用落 `BeansLog`。

## 4. 核心算法

### 4.1 公历 → 农历 / 干支（`services/lunisolar.py`）
- 内置 1900–2100 农历月表（十六进制），`solar_to_lunar()` 得到年月日 + 闰 + 干支纪年。
- **干支纪日**：锚点 `1900-01-31`，`idx=(base+days) % 60`（已验证 2000-01-01 = 戊午）。
- **纪年**：`(year-1984)%60`（1984 甲子）。
- **月柱**（五虎遁）：`寅月干=(年干%5)*2+2`；地支 `月%12`（子=0）。
- **时柱**（五鼠遁）：时支 `((hour+1)//2)%12`；时干 `(日干%5)*2 + 支`。
- 干支配对用 CRT 对齐 60 甲子序号（`ganzhi_from_sb`）。

### 4.2 八字排盘（`services/bazi.py`）
- 四柱（年/月/日/时干支）→ 各柱天干地支、五行、藏干、**十神**（以日主为基准查五行生克 → 比劫/食伤/财/官/印，阴阳分偏正）。
- 五行统计（含藏干）、缺失五行。
- **大运**：阳男阴女顺行、阴男阳女逆行；10 年一运，输出 8 步干支 + 起运岁。

### 4.3 称骨论命（`services/chenggu.py`）
- 60 甲子年骨重表 + 农历月/日/时辰骨重表，四数求和 → `X两Y钱` → 查称骨歌诀（<7两1 全部 51 档）。

### 4.4 六爻（`services/divination.py`）
- 三枚铜钱：3阳=9（老阳/动）、2阳=8（少阴）、1阳=7（少阳）、3阴=6（老阴/动）。
- 6 爻按上下卦匹配 64 卦（八卦三爻位：乾111…坤000），输出本卦 + 动爻。

### 4.5 梅花易数 / 小六壬 / 奇门 / 大六壬
- 梅易：两数取先天卦序（乾1…坤8）定上下卦，数和取动爻 → 本卦 + 变卦（动爻翻转）。
- 小六壬：月→日→时在六宫（大安…空亡）顺数定位。
- 奇门：九宫（1坎…9离）布值符、值使、九星、八门（确定性发盘）。
- 大六壬：日/时干支 + 四课 + 三传（贵人十二神采样）。

### 4.6 运势生成（`services/fortune.py`）
- 以（姓名, 目标日期）为确定性种子；日主五行与当日天干五行相同 → 加分；缺失五行影响基线。
- 产出 `luck / score / categories / yi / ji / color / direction / summary`。

## 5. SSE 协议（AI 流式）

任一 `*/stream` 接口返回 `text/event-stream`：
```
data:{"draw":{...卦象/签文...}}     ← 可选的起卦首帧
data:{"text":"增量文本…"}            ← 逐帧追加
data:[DONE]                          ← 结束
```
- 无 `OPENAI_API_KEY` 时，返回 `data:{"error":"AI 功能需要配置 LLM…"}` 与 `[DONE]`（不崩溃）。
- 前端 `api/client.js#streamSSE()` 用 `fetch` + `ReadableStream` 解析 `data:` 帧，逐字渲染。

## 6. AI 接入（`services/ai.py`）

| env | 默认 | 说明 |
|---|---|---|
| `OPENAI_API_KEY` | 空 | 未配置 → AI 接口返回提示错误 |
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` | 兼容任意 OpenAI 兼容网关 |
| `OPENAI_MODEL` | `gpt-4o-mini` | 对话模型 |

- `stream_chat(messages, system, temperature=0.8)`：SSE 增量生成器（异步）。
- `complete(...)`：非流式完成（八字 AI 分析用）。
- 每个 AI 能力一套 system prompt（道长 / 解卦 / 命书 / 姓名），提高输出质量。

## 7. 内容数据集（`services/qian_data.py`）
- **64 卦全量**：`GUA_DATA[64]`，每卦含 `order/name/full/upper/lower/guxing/guaci/xiang/baihua/summary/yao[6]`（爻辞+白话解），对齐线上返回格式。
- **观音灵签**：`100` 条结构（`no/qian/title/text/interpret`）。
- **诸葛神算**：`384` 条结构（`no/text/interpret`）。
- 数据为独立模块，可整体替换；灵签/神算的正文文本为结构完整占位，**扩展点**：将真实全量签文填入即可（字段不变，无需改代码）。
