# 「天格」全栈复刻 — 概要设计

## 1. 背景与目标

原站 `https://www.buhuo.xin`（天格）是一个命理 SaaS 平台：uni-app (Vue) 前端 + Node API + 数据库。
通过抓包遍历，已还原其 **44 个页面**、**约 85 个后端接口**、统一响应契约与「心识豆 + VIP 配额」计价模型。

本项目用 **FastAPI + SQLite**（`app/`）与 **React (Vite)**（`frontend/`）完整复刻该平台，并产出本概要设计与《详细设计》。

**已确认决策**：全功能复刻；数据库 SQLite；命理算法用可运行的真实规则、内容数据集全量内嵌；AI 只接真实 LLM（需配置 `OPENAI_API_KEY`）。

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | FastAPI + SQLAlchemy 2.0 + Pydantic v2 | 异步流式（SSE）支持好，类型安全 |
| 数据库 | SQLite（ORM 抽象，生产可切 MySQL/PG） | 零配置开箱即跑 |
| 鉴权 | JWT（python-jose）+ passlib(bcrypt) | `Authorization: Bearer` / `X-Uid` 头 |
| 验证码 | Pillow 生成图形验证码 + 内存态校验 | 原站契约 `{b64s,id}` |
| 内容数据 | 内嵌 64 卦全量 / 观音灵签 100 / 诸葛神算 384 | Python 数据模块，可扩展 |
| AI | OpenAI 兼容 SSE 客户端（httpx） | 命书 / AI解卦 / AI道长 / 姓名AI |
| 前端 | Vite + React 18 + React Router + axios | Hash 路由，复刻 uni-app 页面结构与道家美学 |
| 流式 | fetch + ReadableStream，逐帧打字机渲染 | `data:{json}` 协议 |
| 测试 | pytest + TestClient | 端到端接口测试 |

## 4. 模块划分

### 4.1 认证与会话
- 图形验证码 `GET /api/v1/captcha`（b64 图片 + id），登录/注册需校验。
- 注册（用户名/邮箱 + 验证码），**首次注册赠送 50 心识豆**，邀请码双方各 +20。
- 登录签发 JWT（7 天），前端存 `localStorage`，axios 拦截器带 `Authorization`/`X-Uid`。
- 401 统一返回 `{code:401,msg:"未授权访问",reason}`，前端自动跳登录。

### 4.2 用户 / 成员
- 用户中心 `user/detail|info|entitlements|invitation|solar-to-lunar`。
- **成员（出生信息）**：`members` 增删改查，作为运势/命书/合盘的输入（姓名/性别/公历农历/年月日时/时区/关系）。

### 4.3 心识豆与 VIP（计价核心）
- 工具类型 → `{每日免费次数, 单次消耗豆}`。
- 计费 `services/beans.charge()`：**先用每日免费次数（白嫖），超出扣豆**；VIP 按等级打折（vip1/2/3 → 9/8/7 折）。
- 充值包 `beans/package/list`、兑换码 `beans/code/redeem`、流水 `beans/log`。
- VIP `vip/order`（本地占位支付，生产对接支付网关）。

### 4.4 运势预测
- `fortune/today|thisWeek|thisMonth|thisYear|thisDayun|oneLife`
- 输入成员 + 目标日期 → 八字服务推导日主五行 → 与当日干支生克加权 → 生成 **综合评分 / 五大维度 / 宜忌 / 幸运色 / 幸运方向**。

### 4.5 占卜
- 六爻：5 种起卦法（时间/手摇/数字/随机/AI），三枚铜钱起 6 爻，匹配 64 卦。
- 梅花易数：数字/时间定上下卦 + 动爻 → 本卦/变卦。
- 小六壬：月日时起课定六宫（大安…空亡）。
- 奇门遁甲：九宫时局（宫/星/门）。
- 大六壬：四课三传。
- **签卦**：64 卦 / 观音灵签 / 诸葛神算，`random/q` 抽取 + `random/ai/stream` AI 解卦（SSE）。

### 4.6 命书（AI）
- 八字排盘（四柱/十神/藏干/五行/大运）、称骨论命、八字/紫微/天命命书、十年之约。
- 生成结果落 `Mingshu` 表，**生成后免费回看**。

### 4.7 姓名 / 手机 / 起名
- 姓名分析（SSE）、手机号数理分析、智能起名；`tool-history` 记录。

### 4.8 合盘
- `hepan/create`（婚姻/相处/事业 3 类）→ 维度评分 + 契合度 + 建议；`history/detail/delete`。

### 4.9 AI 道长 / 站点
- `daoist/chat/stream`（SSE 流式对话）；`site/stats*` 站点统计；`content-safety/check`。

## 5. 数据流（示例：今日运势）

```
前端 FortunePage(fortune/today)
  → 校验登录(拦截器)  → GET /api/v1/fortune/today?member_id=1
  → fortune.py: charge() 每日免费/扣豆 → BeansLog 流水
  → member_to_fortune_input(): lunisolar 推导四柱 + bazi.compute 五行
  → fortune.generate(): 与当日干支生克 → {score, categories, yi, ji, color, direction}
  → 更新前端口径 → 更新余额
```

## 6. 鉴权与安全
- JWT 签名密钥 `SECRET_KEY`（env），含 `iat/exp`。
- 密码 bcrypt 加盐哈希；验证码一次性使用 + 5 分钟有效期。
- 401 授权拦截中间件；全局异常 → `{code,msg,reason}`。
- 内容安全：`content-safety/check` 敏感词过滤。

## 7. 部署拓扑
- 本地：`uvicorn app.main:app`（:8000）+ `npm run dev`（:5173，代理 /api）。
- 生产：nginx 反代 Vite 静态资源 + Uvicorn（多 worker）；DB 换 MySQL/Postgres；支付与短信对接真实网关；AI 配置真实 LLM Key。

## 8. 非功能
- **性能**：SQLAlchemy 连接池；常用查询建索引（uid/记类型）。
- **可扩展**：内容数据为独立数据模块；算法与路由解耦；VIP 折扣、每日免费次数为配置表。
- **可测试**：pytest 端到端覆盖核心链路。
